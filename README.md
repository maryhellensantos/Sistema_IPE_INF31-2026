# Sistema_IPE_INF31-2026
Repositório destinado ao armazenamento e compartilhamento dos arquivos, códigos-fonte e documentações do Trabalho de Conclusão de Curso (TCC), permitindo a continuidade do desenvolvimento do projeto pelo novo grupo.
Todos os códigos estão comentados, portanto não há com o que se preocupar.
O arquivo principal é o app.py, responsável por conectar o banco de dados ao sistema e integrar as funcionalidades. Já a pasta Models contém todas as classes e métodos do sistema, conectando-se ao app.py.
